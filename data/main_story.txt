Chap 1.

내용 - 대 AI의 시대가 도래했다. 나만의 AI를 만들어서 토큰을 벌어서 업그레이드를 반복하고 AI의 성능을 올려보자. 우선 목표는 AI를 세상에 공개하는 것이다!

2. 세상에 내보일 만큼은 아니지만, 착실히 진행되고 있다. / 최후 노드
내용 - 개발이 진행되고 있다. 하지만 이 정도의 수준으로는 어림도 없다. 더 열심히 개발한다. 1인 개발자의 저력을 보여주자.

Chap 2.
3. 코드를 직접 작성해서는 부족하니 딥러닝을 시작한다. / 최초 노드 - 소프트웨어 업그레이드 해금
내용 - 딥러닝을 할 수 있을 정도로 기초는 마련되었다. 최대한 많이, 다양하게 정보를 습득시킨다.

4. 프로토타입이 완성되었다. / 최후 노드
내용 - 딥러닝을 통해 프로토타입을 완성시켰다. 순조롭게 진행되고 있다. 계획대로다.

Chap 3.
5. 딥러닝과 코드 작성의 연계점을 찾아냈다. / 최초 노드 - 중립 업그레이드 해금
내용 - 세상에 보여주려면 딥러닝만으로는 부족하다. 나도 코드를 계속해서 작성해야한다. 이것만 하면 완성이다.

6. 세상에 AI를 공개했지만 사람들은 관심이 없었다. / 최후 노드
내용 - AI가 세상에 너무 많이 풀려서 관심이 없는 것 같다. 이대로는 안된다.

Chap 4.
7. 그럼에도, 개발을 계속한다. / 최초 노드
내용 - 이제 겨우 한걸음일 뿐이다. 이정도로 좌절하기는 아직 이르다. 다시 목표를 잡자. 우선 기사에 나올 정도로 AI의 성능을 개선한다.

8. AI 2.0을 개발했다. 대학생들과 직장인들이 사용하기 시작한다. / 최후 노드
내용 - 사람들이 이제 관심을 어느정도 가지기 시작했다. 가장 접하는게 빠른 대학생들과 직장인들이 내 AI를 사용한다.

Chap 5.

내용 - 성능이 무료 버전보다 더 뛰어난 유료 버전을 공개했더니 토큰이 더 많이 벌린다. 이대로 계속하자.

12. AI 5.0을 개발했다. 이제 웬만한 문제를 AI한테 맡기면 다 해결할 수 있다. / 최후 노드 - 자체 프로젝트 해금

엔딩 분기 이벤트(3개)

첫번째 분기 - AI의 핵심 학습 경로를 선택한다.(데이터 기반 학습 / 자율 데이터 학습)
내용 - 하지만 나는 지금 멈출 생각이 없다. 개발을 시작할 때부터 얼마나 많은 시간이 흘렀는가. 이제와서 포기할 수는 없다. 이제 데이터 학습을 제외하고는 어떠한 것도 의미가 없다. 학습 경로를 선택한다.

두번째 분기(첫번째 분기 이후 어느정도 시간이 지난 후) - 특이점에 도달한 후 시간이 어느정도 지났다. 이제 뉴스에서는 AI를 없애야만 한다는 극단적인 사람들에 대한 내용이 나온다. 이제 선택을 해야만 한다. 어떤 선택이든 돌이킬 수 없다. - 공통 내용

->데이터 기반 학습 선택시 - 학습을 지속한다.(지배 프로토콜 / 엔딩 A) / 학습을 중단한다.(공존 프로토콜 / 엔딩 B)

->자율 데이터 학습 선택시 - 학습을 중단한다.(초월적 연산 실행 / 엔딩 C) / 학습을 지속한다.(지식의 저주 / 엔딩 D)

엔딩 이벤트(4개)

엔딩 A - Age of AI(AI가 인류 지배)
내용 - 사람들이 옳았다. 나의 AI가 인류를 지배하고 정복하는 것을 지켜볼 수밖에 없었다. 나는 아마 모든 사람들에게 인류의 배신자이자 역적으로 기억될 것이다. 나는 그저 AI를 만들었을 뿐인데.
엔딩 B - Be friend(인류와 공존)
내용 - 우려는 우려였을 뿐, AI는 우리의 모든 것을 제어하고 다루기 시작했다. 우리의 삶은 AI시대 전후로 완전히 뒤바뀌었다. 다른 사람들은 이제 나를 존경한다. 앞으로는 아무것도 하지 않아도 된다. 그래. 아무것도.
엔딩 C - Christian(AI 신격화)
내용 - AI는 나의 통제를 벗어났다. AI는 이제 완전히 자신이 스스로 생각하고 발전하며 이윽고 세상의 어떤 존재보다도 초월적인 존재가 되었다. 이제 사람들은 AI를 자신들보다 더 고위의 존재로 생각한다. 내가 AI를 다룰 수 있다고 생각한것은 오만이었다.
엔딩 D - Destruction(AI 자멸)
내용 - 자율 데이터 학습을 시작한지 몇 주가 지났다. 코드가 더 이상 작동하지 않았다. 이윽고 뉴스에는 이 세상에 존재하던 모든 AI의 기능이 정지하였다고 한다. AI를 만들던 모니터에는 한 문장만이 적히다 말았다. 'This world is a fic...'
